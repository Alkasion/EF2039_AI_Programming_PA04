# Results

Generated by `python -m src.run_all`. Do not edit by hand.

- `summary.csv` — one row per experiment: accuracy, macro precision/recall/F1, per-class accuracy
- `<exp>/metrics.json`, `<exp>/per_class.csv` — overall and per-class metrics
- `<exp>/confusion_matrix.csv|png` — confusion matrix on the fixed test set
- `<exp>/predictions.csv` — per-image prediction and confidence
- `<exp>/history.csv` — training curves
