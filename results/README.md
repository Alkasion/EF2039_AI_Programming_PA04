# Results

Generated by `python -m src.run_all`. Do not edit by hand.

- `summary.csv` — one row per method, mean and std over the 5 seeds of: share of sharp / defocus / motion
  test photos classified correctly, balanced accuracy, accuracy, precision / recall / F1 (blurry), ROC-AUC
- `summary_per_seed.csv` — the same metrics for every single run
- `timing.json` — device used and training time per experiment
- `<exp>/seed<seed>/` — one trained model; `laplacian_baseline/` has the same files without seeds
- `.../metrics.json` — all metrics for one run
- `.../confusion_matrix.csv|png` — rows: true photo type (sharp/defocus/motion), columns: predicted label
- `.../predictions.csv` — per-image prediction and P(blurry)
- `.../history.csv` — training curves (models only)
- `figures/` — `samples.png`, `per_type_accuracy.png`, `culling_demo.png`
