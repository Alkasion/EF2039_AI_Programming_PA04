# Results

Generated by `python -m src.run_all`. Do not edit by hand.

- `summary.csv` — one row per method: share of sharp / defocus / motion test photos classified correctly,
  balanced accuracy, accuracy, precision / recall / F1 for the blurry class, ROC-AUC
- `timing.json` — device used and training time per experiment
- `<exp>/metrics.json` — all metrics for one method
- `<exp>/confusion_matrix.csv|png` — rows: true photo type (sharp/defocus/motion), columns: predicted label
- `<exp>/predictions.csv` — per-image prediction and P(blurry)
- `<exp>/history.csv` — training curves (models only)
- `figures/` — `samples.png`, `per_type_accuracy.png`, `culling_demo.png`
